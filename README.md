# Industry-Facing Website

This is an industry-facing GitHub Pages/Jekyll website for Etienne Nzabarushimana, PhD, MPH.

## Pages

- Home: `index.md`
- About: `about.md`
- Research & Translational Focus: `research-translational-focus.md`
- Selected Projects: `selected-projects.md`
- Publications: `publications.md`
- Skills: `skills.md`
- Leadership & Teaching: `leadership-teaching.md`
- Contact: `contact.md`

## Deployment

To use this as the main GitHub Pages site, copy these files into the repository `nzabarushimana.github.io` and push to the main branch.

To keep it as a separate section inside an existing academic website, copy the page files into a subdirectory such as `/industry/` and update the permalinks accordingly.
